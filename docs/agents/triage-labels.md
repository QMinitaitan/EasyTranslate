# Triage Labels

下表将技能中的五种分流角色映射到 GitHub 标签。

| Role | GitHub label | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格完整，可交给 Agent 执行 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不计划处理 |

技能提到某个分流角色时，使用对应的 GitHub 标签。
应用标签前检查远程已有标签，复用同名标签；
确实需要应用且标签缺失时，再创建该标签。

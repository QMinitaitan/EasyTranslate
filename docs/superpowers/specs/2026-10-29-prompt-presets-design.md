# 系统提示词预设：已确认设计

状态：用户已确认全部设计选择；实现、代码审查与最终离线验证已完成。正式规格为 [Issue #13](https://github.com/QMinitaitan/EasyTranslate/issues/13)，本文保留设计依据与验证记录。

## 目标与已确认决定

用户希望提供多个系统提示词预设，默认帮助理解软件工程技术代码名词，提供合适的翻译、记忆技巧和适当拓展。

- Q1 已确认：技术术语给出译法、简短解释和记忆技巧；技术段落先完整翻译，再解释关键术语；代码保留原样并解释关键名称；普通文本按常规翻译处理。仅在有助于理解时补充相关概念或易混点。
- Q2 已确认：首批三个可编辑预设：“软件工程术语学习”（默认）、“简洁直译”、“自然表达”。
- Q3 已确认：在翻译弹窗中统一快速切换预设，不采用仅在每引擎设置页选择的方案。
- Q4 已确认：旧内置默认升级为术语学习；原有每引擎自定义提示词完整保存为按引擎命名的独立可选预设，供以后手动选择；升级后默认选择术语学习。
- Q5 已确认：沿用完整纯文本结果，短标签与换行组织内容；复制、朗读和历史包含整个结果。单个术语通常 3–6 行，段落最多解释 3 个关键术语，拓展最多 1 条且可省略；解释跟随目标语言，保留必要中英文术语对照。
- Q6 已确认：全应用记住最后一次预设选择，下次划词、切换支持提示词的引擎及重启应用后沿用；首次使用默认术语学习。
- Q7 已确认：统一预设作用于所有支持提示词的引擎；其他引擎继续正常翻译、参与竞速，并在界面标明不支持提示词预设。
- Q8 已确认：弹窗有原文时，切换预设立即取消旧会话并使用新预设重新翻译；没有原文时只记住选择。
- Q9 已确认：在设置中统一编辑三个预设，弹窗提供进入编辑页的入口；修改保存在本地，由所有支持提示词的引擎共享，可单独恢复某个预设的内置文本。

领域名称见根目录 GLOSSARY.md 的“术语学习”和“提示词预设”。

## 实施前核实的行为

- `src/views/SettingsApi.vue` 为 DeepSeek、OpenAI 提供每引擎一个可编辑提示词，没有预设选择或全局提示词。设置采用草稿和防抖保存。
- `electron/providers.cts` 内置提示词要求只翻译、不解释。
- `electron/provider-service.cts` 将提示词发送为 system 消息，原文单独作为 user 消息；支持替换 `{{target}}`，`{{src}}` 当前被清空。
- DeepL 不使用提示词。Bing、Google 的兼容适配使用提示词，但目前不展示提示词编辑入口。
- `electron/config-store.cts` 会用已保存的提示词覆盖元数据默认值，仅修改内置默认不能升级已有配置。
- `src/views/Popup.vue` 展示纯文本；完整结果用于复制、朗读与历史，没有独立的译文和学习说明字段。

### 快速切换的现有交互事实

`src/views/Popup.vue` 当前切换引擎或目标方向时，有原文即重新翻译，并以新会话替代旧会话。当前没有成功结果上的常驻重新翻译按钮，仅错误态有重试按钮。配置更新通知本身不触发重译。

设计问题已全部确认。用户以“这四项都按建议”确认剩余选择，并单独再次确认了 Q4、Q5、Q8、Q9。

## 预设与输出要求

- 软件工程术语学习：按 Q1、Q5 区分文本类型；术语有歧义时说明，不臆测上下文；记忆联想不冒充真实词源，不编造事实。普通生活文本直接翻译。
- 简洁直译：准确翻译，仅输出译文，保留段落、代码、标识符和必要术语。
- 自然表达：含义、语气和事实保持准确，措辞符合目标语言习惯，仅输出译文。
- 具体内置文本以 `electron/prompt-presets.cts` 为事实来源。行数与解释数量是提示词约束，模型是否遵循不属于离线测试能够证明的范围。

## 配置、会话与界面

- `promptPresets` 以稳定 ID 保存具名文本，`selectedPromptPreset` 保存全应用选择。按预设 ID 合并修改，切换选择不会覆盖在另一窗口保存的文本。
- 首次读取旧配置时在内存中迁移，下一次成功保存配置时一并落盘。迁移只将不完全匹配旧默认且非空的提示词导入为独立预设；保留原每引擎字段，后续读取不重复导入，也不覆盖已编辑的导入文本。
- 翻译请求只携带预设 ID，主进程从已保存配置解析文本，为整个单引擎或竞速会话保存同一份提示词快照。主进程校验预设 ID，拒绝不存在的预设。
- 快速切换先取消旧工作并保存选择，保存成功后重新翻译；保存失败时回退选择并显示错误。保存期间的新翻译使用已保存的选择，保存完成不重复发起已被新操作替代的翻译。
- 弹窗展示预设选择器、编辑入口及不支持提示词的引擎说明；结果标签保留本次会话实际使用的预设名称，普通翻译引擎不显示学习预设标签。
- 设置增加独立“提示词预设”页面，支持自动保存、立即保存或重试、按内置预设恢复文本。已导入的旧自定义预设同样可以编辑。
- 预设编辑失败保留草稿；复用现有待保存设置机制，在页面退出与原生退出时继续管理待保存内容。空提示词不能覆盖有效的已保存文本。

## 验收范围

- 首次使用与升级默认选择术语学习；切换、编辑、恢复文本后配置可重新加载。
- 内置默认不误判成自定义；旧自定义完整保留，迁移可重复加载而不重复导入。
- 单引擎及竞速使用相同的已保存预设；目标语言占位符替换正确，原文保持独立 user 消息；DeepL 继续使用原协议。
- 切换后取消旧会话，迟到结果不覆盖新结果；无原文时只保存选择。
- 保存失败保留旧配置或未保存草稿，不偷偷改用其他预设；新旧操作交错时不重复翻译旧意图。

# Windows helper comparison, frozen before product change

Run unchanged EasyTranslate integration 9d6fc07 (no popup preheat) with the original helper and the candidate in round-robin order inside the same isolated application process. Only the injected public selection dependency differs. Both run Windows PowerShell -NoProfile -NonInteractive -Sta; the candidate loads System.Windows.Forms and calls SendKeys.SendWait('^c') instead of compiling C# P/Invoke. Both retain the existing 120 ms release wait, 700 ms clipboard poll budget, sentinel and supported-format restoration. No installed application, personal config/history or external provider request is used.

Use 20 selected-text attempts per variant, alternating variant order each round, including English/Chinese and every-third-round source equal to the previous clipboard fixture. Add two empty-selection and two actual failing-process attempts per variant. Retain every attempt, including wrong foreground, timeout and failures. Record all four fixture formats text/HTML/RTF/opaque 2x2 image, and keep the user's original supported clipboard DataObject only in the outer runner's memory for restoration.

Exercise real Alt+Q, the real selection service, native foreground WinForms source, main/preload/Vue, isolated JSON history and the real adapter with exactly 50 ms in-process test transport. Record capture/helper/release-wait/poll/restoration and DOM response stages. Sample the entire application descendant tree with the frozen 100 ms .NET sampler and add foreground HWND to that sampler. Report its overhead and working-set double-count limitation. Idle samples are 30 s before and after all repeated attempts. This is a paired helper experiment, not a new cold-start sample or a replacement for the original frozen application baseline.

Accept a product helper change only if measured helper and capture medians improve, the warm P95 does not exceed the frozen max(15%,50 ms) degradation tolerance, no extra incorrect/empty captures appear, and supported clipboard/focus semantics hold. Other application stages and preheat gains are not credited to the helper. A failure or an inconclusive result may retain the original helper, as #9 explicitly permits. Do not shorten waits, add a resident process or relax thresholds after seeing data.

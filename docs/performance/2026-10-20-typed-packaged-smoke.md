# T1 typed compatibility and bundled-ASAR native smoke

Both short runs used the exact frozen external launcher/native driver with 50 ms in-process HTTPS transport, isolated config/history/profile, actual Alt+Q, real PowerShell selection helper and foreground WinForms TextBox. These are compatibility smokes, not statistically useful performance comparisons.

1. `runs-typed-smoke`: repository `D:\codex_worktree\easytranslate-t1\EasyTranslate`, original Electron 43.2.0 executable, production-built typed contracts and `dist-electron/preload.cjs` from this worktree. First selected invoke and repeated selected invoke both reached matching source/result DOM and saved exactly two synthetic history entries. Empty selection produced no adapter request/history entry. Text/HTML/RTF restored on all three captures. Foreground matched all three emissions; two total BrowserWindows; exit code 0.
2. `runs-asar-smoke`: repository root set to `D:\codex_worktree\easytranslate-t1\EasyTranslate\release\win-unpacked\resources\app.asar`, launcher required the main and selection modules from inside that same ASAR, using the original Electron 43.2.0 executable. This exercised the bundled main, shared compiled contract, typed compiled preload and production Vue assets. Both selected invocations reached expected result DOM and saved exactly two synthetic history entries; empty selection made no adapter call/history. Text/HTML/RTF restored on all three captures. Foreground matched all three emissions; two total BrowserWindows; exit code 0.

Per-run `driver.jsonl`, `events.jsonl`, `resources.csv`, stdout/stderr and regenerated `summary.json` are retained outside Git under `E:\EasyTranslate-implementation-notes-20261020\benchmark`. Statistics are archived in [typed smoke JSON](2026-10-20-typed-smoke.json) and [ASAR smoke JSON](2026-10-20-asar-smoke.json). There were no app errors; Electron logged the benchmark observer's deprecated console-message signature. Managed app/source processes were stopped and supported original clipboard data restored by the runner.

The ASAR run verifies that bundled relative paths and typed preload work under Electron's ASAR resolution. It is not a launch of the packaged `EasyTranslate.exe`, an NSIS install, or an installed-product smoke. Those remain explicit later validation. No application source, real user config/history, installed application, network provider or personal credential was mutated by this benchmark task.
